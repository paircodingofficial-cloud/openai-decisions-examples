# 얼굴 사진 예제의 출처

샘플은 공개된 사진의 파일 설명과 라이선스를 확인하여 교육용으로 내려받았습니다. 사진 속 인물이 이 실습을 지지하거나 모델 학습·성능을 보증한다는 의미는 없습니다. 얼굴 인식·신원 확인용이 아니라 외모상 연령대 추정 흐름을 설명하는 예제입니다.

각 사진의 저작권·라이선스는 아래 출처를 따릅니다. CC BY-SA 사진과 그 파생물은 해당 라이선스를 유지해야 합니다. 원본 이미지를 새로 편집하지 않았으며, 일부는 Wikimedia가 제공하는 축소판입니다. 노트북은 API 입력을 위해 메모리에서 최대 768px JPEG로 변환합니다. 공개 인물이라는 편향과 사전학습 지식 때문에 이 여섯 장을 정확도 벤치마크로 사용하지 않습니다.
